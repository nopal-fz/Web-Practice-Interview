## Temuan

| # | Rule | Prioritas | Temuan |
|---|---|---|---|
| F1 | R-25 (Kontras) | **HIGH** | `text-zinc-400` di atas `bg-white` ≈ 2.6:1 untuk teks kecil (12px). Terjadi di: tag di detail soal, label "Lihat jawaban" di daftar soal, jumlah kategori di landing page. Gagal WCAG AA (min 4.5:1). |
| F2 | R-03 (Tap target mobile) | **HIGH** | Input filter, tombol, tautan pagination, dan tautan header nav di bawah 44px pada mobile (py-1.5 atau py-2 + text-sm ≈ 32-36px). Gagal standar tap target nyaman. |
| F3 | R-27 (State error/404) | **HIGH** | Tidak ada `error.tsx` atau `not-found.tsx` kustom. Error DB atau 404 menampilkan halaman default Next.js yang tidak konsisten dengan desain. |
| F4 | R-21 (Dark mode) | **MED** | Mode terang dipaksakan tanpa alasan branding. Opsi toggle tidak diimplementasi. (Dokumentasikan di DESIGN.md sebagai pertimbangan masa depan; perbaikan penuh diluar scope fix kali ini.) |
| F5 | R-32 (Focus visibility) | **MED** | `QuestionForm` memakai `outline-none` pada fieldClass, menghapus focus-visible outline global, hanya mengandalkan perubahan warna border (teal-600 ≈ 3.7:1, memenuhi ambang 3:1, tapi kurang mencolok dari outline). |
| F6 | R-20 (Identitas) | **LOW** | Header hanya teks "Bank Soal Interview". Tidak ada motif identitas visual. Untuk tool utilitas ini, dampaknya rendah. |
| F7 | R-35 (Verify) | **HIGH** | Build dan lint harus dijalankan ulang setelah semua perbaikan diterapkan, untuk memastikan tidak ada regresi. |
